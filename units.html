Defenkov 유닛 형태 후보 — 일본풍 미니멀

전부 Unity 프리미티브(구·캡슐·실린더) 또는 절차적 다면체로 조립 가능한 것만.
봐주실 것 —
① 확대 뷰에서 마음에 드는 것 2~3개
② 그게 실제 크기 줄에서도 구분되는가
③ 굴러갈 것 / 뛸 것을 다르게 줄지, 하나로 통일할지

후보 확대 · 셀 크기의 약 2.5배

실제 크기 화면 16 × 26px — 이게 진짜입니다

16px에서는 실루엣만 남습니다. 눈·무늬는 사라집니다. 그래서 판정 기준은 "귀엽나"가 아니라 "옆의 것과 구분되나"입니다.

프리미티브 구성 · 이동

이동 방식이 형태를 정합니다 — 굴러갈 것은 회전축이 있어야 하고(경단·다루마·팽이), 뛸 것은 착지 스쿼시가 읽혀야 합니다(토끼·개구리). 문어·오니기리는 미끄러지는 쪽입니다.

16px에서 가장 잘 구분되는 것은 실루엣이 비대칭인 것입니다 — 토끼(귀 2개)·고양이(귀 2개)·팽이(역삼각). 경단·다루마·개구리는 둥근 덩어리라 서로 헷갈릴 수 있습니다.

⚠ CSS 근사입니다. Unity에선 실제 3D라 명암·그림자가 붙어 실루엣이 더 또렷합니다.
